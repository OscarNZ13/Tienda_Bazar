# 🛍️ Tienda Bazar

Tienda en línea para un bazar y librería: catálogo de productos, carrito de compras, pedidos, reseñas y administración de usuarios.

## ✨ Funcionalidades

- Registro e inicio de sesión con roles y estados de usuario.
- Catálogo de productos con imágenes.
- **Carrito de compras** y generación de **pedidos** con su detalle.
- **Reseñas** de productos.
- Panel para administrar productos y usuarios.

## 🚀 Cómo correrlo

1. Requisitos: .NET 8 SDK y SQL Server (LocalDB sirve).
2. Creá la base de datos con el script `Tienda_Bazar/BD_ready_Migration.sql`.
3. Revisá `BazarLibreriaConnection` en `appsettings.json`.
4. `dotnet run --project Tienda_Bazar`
